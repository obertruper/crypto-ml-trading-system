## ✅ ВЫПОЛНЕННЫЕ ИСПРАВЛЕНИЯ

### 1. Фиксированный Bias (anti_collapse_components.py)
```python
# БЫЛО:
self.class_bias = nn.Parameter(torch.zeros(num_timeframes, num_classes))

# СТАЛО:
self.register_buffer('class_bias', torch.zeros(num_timeframes, num_classes))
```
**Результат**: Bias теперь не обучается и остается фиксированным

### 2. Настройка direction_bias в config.yaml

#### В секции model:
```yaml
direction_bias:
  - -0.8  # LONG bias (снижаем до ~15%)
  - -0.8  # SHORT bias (снижаем до ~15%)
  - 0.5   # FLAT bias (повышаем до ~70%)
```

#### В staged_training.stages[0]:
```yaml
direction_bias:
  - -0.8  # LONG bias (синхронизировано с model)
  - -0.8  # SHORT bias (синхронизировано с model)
  - 0.5   # FLAT bias (синхронизировано с model)
```

### 3. Оптимизация Loss функции
```yaml
loss:
  class_weights: [3.5, 3.5, 0.2]  # Усиливаем LONG/SHORT
  use_focal_loss: true             # Фокус на сложных примерах
  label_smoothing: 0.05            # Минимальное сглаживание
  flat_preservation_weight: 0.1    # Снижаем доминирование FLAT
  min_flat_ratio: 0.5              # Целевая доля FLAT 50-70%
  entropy_regularization: 0.25     # Умеренная регуляризация
```

### Проблема при реальном обучении:
- Модель НЕ получает direction_bias из конфига
- Вместо настроенных значений использует fallback: `[-0.5, 0.0, 0.5]`
- Это приводит к быстрому схлопыванию в SHORT класс
