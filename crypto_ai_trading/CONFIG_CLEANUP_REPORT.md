## 📋 УДАЛЕННЫЕ ФАЙЛЫ

### Из директории config/:
1. **config_clean.yaml** - альтернативный конфиг для чистого запуска
2. **config_curriculum.yaml** - конфиг для curriculum learning (устарел)
3. **config_fixed_collapse.yaml** - временный конфиг для исправления схлопывания
4. **config_production.yaml** - production конфиг (дублировал основной)
5. **config_recovery.yaml** - конфиг для восстановления после сбоев
6. **server_profiles.yaml** - профили серверов (не используется)
7. **__pycache__/** - кэш Python

## ✅ ОСТАВШИЕСЯ ФАЙЛЫ

В директории `config/` остались только:
- **config.yaml** - основной конфигурационный файл
- **__init__.py** - для Python пакета
