# АНАЛИЗ КОЛЛАПСА МОДЕЛИ - ОТЧЁТ

## Текущая ситуация
Модель постоянно коллапсирует в предсказание одного класса, несмотря на множественные попытки исправления.

## Проведённые эксперименты

### 1. Конфигурация без bias
- **Результат**: Коллапс в 100% FLAT (эпоха 1-2)
- **Энтропия**: 0.000

### 2. Конфигурация с bias [0.3, 0.3, -0.3]
- **Эпоха 1**: Энтропия 0.443, SHORT 2.1%, некоторое разнообразие
- **Эпоха 2+**: Коллапс, энтропия падает до 0.000
- **Результат**: Временное улучшение, затем полный коллапс

### 3. Конфигурация с bias [0.2, 0.5, -0.1]
- **Эпоха 1**: SHORT взлетел до 55.3% (перекос в другую сторону)
- **Эпоха 2+**: Опять коллапс в 100% FLAT
- **Результат**: Bias 0.5 для SHORT слишком сильный

### 4. Конфигурация с bias [0.15, 0.25, 0.0]
- **Эпоха 1**: Энтропия 0.346, лучше баланс
- **Эпоха 2**: Коллапс в 100% FLAT, энтропия 0.000
- **Результат**: Не решает проблему

## Ключевые проблемы

1. **Дисбаланс классов в данных**:
   - FLAT: ~70%
   - LONG: ~15%
   - SHORT: ~15%

2. **Быстрая сходимость к мажоритарному классу**:
   - Модель быстро понимает, что предсказывая FLAT она получает 70% accuracy
   - Loss функция не достаточно наказывает за игнорирование LONG/SHORT

3. **Недостаточная регуляризация**:
   - Label smoothing 0.05 слишком слабый
   - Entropy regularization 0.1 не работает

4. **Learning rate возможно слишком высокий**:
   - 0.00015-0.0002 может быть слишком агрессивным

## Рекомендации для решения

### Срочные меры:
1. **Увеличить label smoothing до 0.15-0.2**
2. **Увеличить entropy regularization до 0.5-1.0**
3. **Уменьшить learning rate до 0.00005**
4. **Использовать более агрессивный bias: [0.5, 0.5, -0.5]**

### Радикальные меры:
1. **Изменить веса классов**: [2.0, 2.0, 0.5] - наказывать за FLAT
2. **Включить focal loss с правильными параметрами**
3. **Использовать undersampling для FLAT класса**
4. **Добавить auxiliary loss для принуждения к разнообразию**

## Вывод
Текущий подход с небольшими изменениями bias не работает. Нужны более радикальные изменения в loss функции и процессе обучения.
