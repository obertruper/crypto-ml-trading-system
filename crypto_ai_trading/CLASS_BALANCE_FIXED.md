# 🎯 ИСПРАВЛЕНИЕ БАЛАНСА КЛАССОВ - ОТЧЕТ

## 📊 Проблема
Модель схлопывалась в один класс:
- До исправления: 100% LONG, 0% SHORT, 0% FLAT
- F1 Score: 0.093 (очень низкий)
- Целевое распределение: 15% LONG, 15% SHORT, 70% FLAT

## 🔍 Найденные проблемы

### 1. Learnable Bias (КРИТИЧЕСКАЯ)
**Файл**: `models/anti_collapse_components.py`, строка 160
```python
# БЫЛО (неправильно):
self.class_bias = nn.Parameter(torch.zeros(num_timeframes, num_classes))

# ИСПРАВЛЕНО:
self.register_buffer('class_bias', torch.zeros(num_timeframes, num_classes))
```
**Проблема**: Bias был learnable параметром и обнулялся при обучении

### 2. Неправильная загрузка конфигурации
**Файл**: `models/patchtst_unified.py`
- direction_bias был в `staged_training.stages[0]`, но модель получала только `config.model`
- Решение: Добавили direction_bias прямо в секцию `model` конфига

### 3. Неоптимальные значения bias и weights
**Файл**: `config/config.yaml`

## ✅ Финальные настройки

### Direction Bias (в config.yaml)
```yaml
model:
  direction_bias:
    - -0.8  # LONG bias (снижаем до ~15%)
    - -0.8  # SHORT bias (снижаем до ~15%)
    - 0.5   # FLAT bias (повышаем до ~70%)
```

### Loss настройки
```yaml
loss:
  class_weights:
    - 3.5  # LONG - сильно усиливаем
    - 3.5  # SHORT - сильно усиливаем
    - 0.2  # FLAT - сильно снижаем
  use_weighted_sampling: true
  use_focal_loss: true
  focal_alpha: 0.25
  focal_gamma: 2.0
  label_smoothing: 0.05
  flat_preservation_weight: 0.1
  min_flat_ratio: 0.5
  entropy_regularization: 0.25
```

## 📌 Рекомендации для дальнейшей настройки

1. **Если FLAT все еще доминирует (>85%)**:
   - Уменьшить FLAT bias до 0.3
   - Увеличить LONG/SHORT bias до -0.6

2. **Если недостаточно LONG/SHORT (<10% каждый)**:
   - Увеличить class_weights для LONG/SHORT до 5.0
   - Уменьшить FLAT weight до 0.1

3. **Мониторинг во время обучения**:
   - Следить за распределением каждую эпоху
   - Корректировать bias если видно схлопывание
   - Использовать early stopping при стабильном распределении

## 💡 Ключевые выводы

1. **register_buffer vs nn.Parameter** - критическая разница для фиксированных параметров

4. **Focal Loss** - помогает с несбалансированными классами
